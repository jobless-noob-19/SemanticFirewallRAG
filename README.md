# Semantic Firewall for Secure RAG

A secure Retrieval-Augmented Generation(RAG) system with a semantic firewall to defend against:

- Prompt Injection
- Jailbreak Attacks
- Retrieval Poisoning
- Hallucinations
- Sensitive data Leakage

## Technology Stack

- Python
- Ollama
- LangChain
- ChromaDB
- Sentence Transformers
